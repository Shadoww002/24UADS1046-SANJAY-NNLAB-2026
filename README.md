# NNLAB 2026 – Neural Network Laboratory

This repository contains all the experiments and mini project completed for the Neural Network Laboratory (NNLAB) course of B.E. AI & DS VI Semester.  
The lab focuses on understanding and implementing different Neural Network architectures using Python and Deep Learning libraries.

---

# 📚 Experiments Included

## Experiment 1 – Perceptron Learning Algorithm
- Implemented Perceptron using NumPy
- Visualized learning using Matplotlib/Seaborn
- Evaluated NAND and XOR truth tables

## Experiment 2 – Multi-Layer Perceptron (MLP)
- Implemented MLP with one hidden layer using NumPy
- Demonstrated learning of XOR function

## Experiment 3 – Three Layer Neural Network
- Implemented Neural Network using TensorFlow
- Classified MNIST handwritten digit dataset
- Demonstrated feed-forward and backpropagation

## Experiment 4 – Hyperparameter Tuning
- Evaluated effects of:
  - Activation functions
  - Learning rate
  - Batch size
  - Epochs
  - Hidden layer size

## Experiment 5 – Convolutional Neural Network (CNN)
- Implemented CNN using Keras
- Classified Fashion-MNIST dataset
- Compared optimizers and filter sizes

## Experiment 6 – Recurrent Neural Network (RNN)
- Implemented RNN using PyTorch
- Time series next-value prediction

## Experiment 7 – Transfer Learning
- Retrained pretrained ImageNet model
- Medical image classification task

# 🚗 Mini Project – Driver Data Analysis & Risk Scoring

This mini project focuses on analyzing driving behavior using mobile sensor data.

## Features
- Driver behavior analysis using:
  - Accelerometer data
  - Gyroscope data
- Driving/Risk score prediction
- Multiple riders and vehicle variations
- Different phone placements and speed conditions

## Techniques Used
- Deep Learning models
- RNN/LSTM based sequence learning
- Data preprocessing and feature engineering
- Model evaluation and performance comparison
